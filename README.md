# 🐦 TwitHub

> Tweet. Reel. Connect. 🚀

TwitHub is a full-featured, Twitter-inspired social media platform built with PHP and MySQL. It combines traditional micro-blogging with modern short-form video reels, direct messaging, and a complete admin moderation system.

## ✨ Features

### 📝 Tweets
- Post text updates (280 characters)
- Upload up to 5 images per tweet
- Attach up to 5 videos per tweet
- Like, comment, retweet, and quote
- Hashtags and mentions

### 🎬 Reels
- Create short-form videos (up to 60 sec)
- Add background music from library
- Mute original audio option
- Vertical feed with autoplay
- Like, save, and share reels

### 💬 Messaging
- Real-time direct messages
- Send photos, videos, documents
- Voice recording and sending
- Block/unblock users
- Online presence tracking

### 🔔 Notifications
- Likes, follows, retweets
- Comments and replies
- Mentions and messages

### 🛡️ Admin Panel
- Dashboard with analytics
- User management
- Tweet moderation
- Reel management
- Music library management

### 🔒 Security
Password hashing using bcrypt
PDO prepared statements for database queries
Session-based authentication
Admin area protection
User blocking capability

## 🛠️ Tech Stack

| Technology | Purpose |
|------------|---------|
| **PHP 8.x** | Backend logic and rendering |
| **MySQL** | Database |
| **PDO** | Database access layer |
| **jQuery** | AJAX and DOM manipulation |
| **Bootstrap 5** | UI framework |
| **Font Awesome** | Icons |
| **Chart.js** | Admin analytics |
| **Wavesurfer.js** | Audio waveform |
| **FFmpeg** | Video processing |
| **PHPMailer** | Email |

## 📦 Installation

### Prerequisites
- PHP 8.x
- MySQL
- Apache with mod_rewrite
- Composer
- FFmpeg
